# SmartNotes Enterprise

## Deskripsi
Aplikasi manajemen catatan berbasis CLI + REST API menggunakan FastAPI dan SQLite.

## Fitur
- REST API (FastAPI)
- CLI Client
- Database SQLite
- Clean architecture

## Instalasi
pip install -r requirements.txt

## Menjalankan API
uvicorn main:app --reload

## Menjalankan CLI
python cli.py

## Struktur
- main.py (API)
- cli.py (client)
- database.py
- models.py
- schemas.py
- crud.py
